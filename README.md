# 한국 베라르 AIT 연구소 홈페이지 개편 시안

승인 로고의 네이비·청록 색상을 적용한 PC·모바일 반응형 정적 미리보기입니다. 기존 운영 사이트를 대체하지 않습니다.

## 구성
- `index.html`: 이미지와 스타일을 내장한 단일 HTML. 빌드/설치 불필요.
- `kait-logo.svg`, `kait-symbol.svg`, `kait-logo-white.svg`: 승인 로고와 심볼 벡터. 글자는 윤곽선 처리.
- `.nojekyll`: GitHub Pages 정적 배포 설정.

## 구현
모바일 메뉴, 내부 이동, FAQ, 서울/대구 위치 전환, 주소 복사, 전화·메일 링크, 기존 자료실 연결. 별도 관리자·예약·상담폼·게시판 데이터베이스는 포함하지 않습니다.

## 제작 및 검수
- HTML/CSS/JavaScript와 SVG는 AI가 직접 코드를 구성했습니다.
- 메인 이미지는 `openai-codex / chatgpt-image-generation`으로 생성한 시안용 이미지입니다. 실제 이용자·기관·훈련 장치를 나타내지 않습니다. 페이지에도 표시했습니다.
- 기관 연락처와 주소는 기존 사이트의 공개 정보를 참고했습니다. 방문 전 운영 장소와 일정을 확인하도록 안내합니다.
- 진행 과정과 FAQ는 상담 전 확인 사항을 정리한 제안 문구로, 공개 전 기관 검수가 필요합니다. 효과를 보장하는 표현과 개인정보가 포함된 사례 목록은 옮기지 않았습니다.
- 검색 제외용 `noindex,nofollow` 메타태그를 유지합니다.
