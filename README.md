## 게시판은 아직 연결하지 않았습니다
사용자 요청에 따라 게시판 데이터·검색·페이지네이션·글쓰기·상담·답글·비밀글 권한 연동은 뒤로 미뤘습니다. 실제 원문은 각 화면의 기존 게시판 링크로 확인할 수 있습니다. 글 수와 페이지 수는 2026-11-06 원사이트 조사 값이며 실시간 데이터가 아닙니다. 민감한 사례 본문, 비밀글, 상담 내용은 복사·공개하지 않았습니다.

## 경로
GitHub Pages의 정적 특성상 파일명 식별자를 유지한 해시 경로로 동작합니다. 예: `#/submenu01_1.php`, `#/submenu05_3.php`. PHP 파일이 실행되는 것은 아닙니다. 실제 적용 시 기존 PHP·게시판 경로에 공통 스킨과 본문을 연결할 수 있습니다. 기존 v1의 `#ait`, `#about`, `#contact` 등은 대응 화면으로 이동합니다.

## 원문과 자료
원문은 http://www.kait.pe.kr/ 의 공개 일반 페이지에서 옮겼습니다. 문구·문헌·표의 내용을 요약하거나 재작성하지 않았습니다. 원문에 포함된 연구·효과 주장과 전문 자격 설명을 독립적으로 검증한 것은 아닙니다. 원본부터 일부 연구 내부앵커 대상과 외부 링크가 불완전하며, 내용은 임의로 고치지 않고 안내를 제공합니다. 주소·운영시간은 기존 게시 내용이므로 방문 전 확인하도록 표시합니다.

## 제작
HTML/CSS/JavaScript·SVG 로고는 AI가 직접 코드 구성했습니다. 메인 인물 사진은 `openai-codex / chatgpt-image-generation` 생성 시안 이미지이며 실제 이용자·기관·훈련 장치 사진이 아닙니다. 서적·Earducator·기존 안내·약도는 원사이트 자료입니다.
